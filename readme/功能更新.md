# ApolloTab 功能更新记录

## v1.5.0 (2026-08-05)

### 新增
- **mypy 类型检查全量接入** (`pyproject.toml` / `.github/workflows/ci.yml`):
  - 新增 `[tool.mypy]` 配置: `disallow_untyped_defs` / `no_implicit_optional` / `warn_return_any` / `warn_unused_configs`；以 `ApolloTab/__init__.py` 为入口经 `follow_imports` 全量覆盖核心库导入链
  - 第三方无 stub 库 (`guitarpro`/`fluidsynth`) 配 `ignore_missing_imports`
  - CI 新增独立 `typecheck` job (ubuntu-latest + Python 3.12)，`mypy` 0 错误才通过
  - dev 依赖新增 `PyQt5-stubs>=5.15.6.0`，使 Qt 函数可获得类型检查
- **GTPNote.vibrato 字段** (`models/note.py`): 新增 `VibratoType | None` 字段，GP7/GP8 `<Vibrato>` 节点的 Slight/Wide 标记落盘为枚举，供 MIDI 合成正弦波揉弦使用

### 修复
- **大批函数签名缺失 / implicit Optional / no-any-return**:
  - `player.py`: 14 处参数改 `T | None = None`；`measure_entries`/`num_to_global`/`groups` 加 `dict[...]` 注解；5 处字典取值返回包 `float()`；`__del__`/`set_theme`/`update_playhead` 等补返回类型；`if note_callback:` 改 `is not None` 避免 truthy-function
  - `tab_renderer.py`: 11 个绘制方法 (`_draw_note_fret`/`_draw_technique_marks`/`_draw_slide_line`/`_draw_hammer_on_arc`/`_draw_bend_indicator`/`_draw_technique_text_labels`/`_draw_stem`/`_draw_beam_flags`/`_draw_rest_symbol`/`_draw_info_bar`/`_draw_time_signature`) 的 `note`/`beat`/`measure` 参数补 `GTPNote`/`GTPBeat`/`GTPMeasure` 类型；`m_layout: MeasureLayout | None`；`drawText` 的 `Qt.AlignRight | Qt.AlignVCenter` 包 `int()` 匹配 overload；`drawPolygon` 传 `QPolygon(diamond)`；`tech_beats` 加 `dict[TechniqueType, list[tuple[int,int,int]]]`；chord 访问加判空
  - `gpif_parser.py`: `_GpifRhythm`/`_GpifSound`/`GP7Parser.__init__` 补 `-> None`；`self.__init__()` 重构为 `_reset_state()` 消除 instance.__init__ 警告；`_parse_dom`/`_parse_score_node`/`_build_model` 开头 `assert self._song is not None` 窄化类型；`mb_data`/`bar_data` 加 `dict[str, Any]` 注解
- **BendData.bend_type 类型**: `str` → `BendType | str`，兼容 GP3-5 传字符串与 GP7/GP8 传 `BendType` 枚举两条路径
- **动态属性 `_parent_beat`**: `note._parent_beat = beat` 改 `setattr`，读取处改 `getattr(note, '_parent_beat', None)`，避免 mypy attr-defined 报错同时不掩盖真实错误
- **pyproject.toml unused mypy override**: 移除未被检查链导入的 `guitarpro.*`/`numpy`/`numpy.*`，消除 `warn_unused_configs` 噪音

### 调整
- `examples/` 三个示例 (`basic_parse.py`/`render_tab.py`/`audio_playback.py`) 的 `main`/`batch_render`/`show_progress`/`format_tuning` 补返回类型注解

## v1.3.1 (2026-07-01)

### 修复
- **播放条与 MIDI 音频不同步** (`player.py`):
  - 根因: `build_timeline()` 原先用 `measure_ticks // n_beats` 把每拍均摊, 导致四分音符与八分音符占用相同时间
  - 修复: 改为按 `beat.duration_value` 累加 tick, 与 `MidiConverter` 的 `_beat_duration_to_ticks()` 计算逻辑保持一致
  - 覆盖场景: 附点音符、三连音、多连音、混合时值小节、空白小节

### 修改文件
| 文件 | 变更说明 |
|------|---------|
| `player.py` | 修复: `build_timeline()` 按实际音符时值累加 tick |
| `__init__.py` / `pyproject.toml` | 版本号 → 1.3.1 |

## v1.1.0 (2026-06-29)

### 新增
- **GP7/GP8 鼓轨 Articulation 解析**: `PercussionArticulation` 数据类映射 GP7/GP8 `<Articulation>` 到 MIDI note

### 修复
