## v1.3.1 (2026-07-01)

### 修复
- **播放条与 MIDI 音频不同步** (`player.py`):
  - 根因: `build_timeline()` 原先用 `measure_ticks // n_beats` 把每拍均摊, 导致四分音符与八分音符占用相同时间
  - 修复: 改为按 `beat.duration_value` 累加 tick, 与 `MidiConverter` 的 `_beat_duration_to_ticks()` 计算逻辑保持一致
  - 覆盖场景: 附点音符、三连音、多连音、混合时值小节、空白小节

### 修改文件
| 文件 | 变更说明 |
|------|---------|
| `player.py` | 修复: `build_timeline()` 按实际音符时值累加 tick |
| `__init__.py` / `pyproject.toml` | 版本号 → 1.3.1 |

## v1.3.0 (2026-06-30)

### 新增
- **ThemeConfig 运行时主题注册** (`utils/constants.py`):
  - `register_theme(name, colors)` / `unregister_theme(name)`: 运行时注册/注销自定义主题
  - 内置主题("dark"/"light")保护：覆盖时被忽略并返回内置实例；缺失键自动用深色默认值填充
- **节拍器通道音量 CC 事件**: 节拍器生成事件时新增 CC#7 事件，避免被其他乐器掩盖

### 修复
- **GP7/GP8 GPIF String 弦号映射方向**: 修复弦号反转映射问题

### 调整
- **节拍器默认 gain**: 调整为 1.5，解决木鱼音色不够突出

### 修改文件
| 文件 | 变更说明 |
|------|---------|
| `utils/constants.py` | 新增 register_theme/unregister_theme |
| `audio/metronome.py` | 默认 gain=1.5; 新增 CC#7 事件 |
| `parser/gpif_parser.py` | 修复弦号映射方向 |

## v1.2.0 (2026-06-30)

## v1.1.0 (2026-06-29)

### 新增
- **GP7/GP8 鼓轨 Articulation 解析**: `PercussionArticulation` 数据类映射 GP7/GP8 `<Articulation>` 到 MIDI note
- **BendType / BendStyle / VibratoType 枚举** (`utils/constants.py`): 对齐 alphaTab

### 修复
- **鼓组音色失效**: `synth_engine.py` CC#0=128 超范围 → 改为 CC#0=1, CC#32=0
- **Bank Select 非法值**: 鼓组 Bank 128 拆分为合法 14-bit (CC#0 + CC#32)
- **通道音色强制覆盖**: 移除 `player.py` 强制覆盖音色逻辑，改由 midi_converter 统一处理

### 其他
- 许可证变更: MPL-2.0 → LGPL-2.1

## v1.0.1 (2026-06-28)

### 新增
- **GP7/GP8 (.gp) 文件原生支持**: 新增解析器链 `gp7_parser.py` / `gpif_parser.py` / `binary_stylesheet.py` / `part_configuration.py`（基于 alphaTab 算法移植）
- **智能调度**: `parse_score(filepath)` 按扩展名自动选择解析器 (.gp3-5 用 PyGuitarPro, .gp 用原生)
- **扩展数据模型**: models 新增 GP7/GP8 专属字段；`RenderMode` 枚举
- **音色库(Bank)选择**: midi_converter 自动发送 Bank Select + Program Change；synth_engine 扩展 control_change/program_change 事件
